# Problem Canvas

> Phase 1 artifact. Fill in every section. Each answer should be <3 sentences.

## Problem statement
_One sentence. Who has the problem, in what situation, and what outcome are they trying to get?_

## Why now
_What has changed in the world, the market, or the company that makes this problem worth solving this quarter?_

## Target user
_Role, segment, size of population. If B2B, name the buyer AND the end user if different._

## Current workaround
_How do these users solve this today? Tools, spreadsheets, manual processes, competitors._

## Success signal
_If we solve this, what would we measurably see change? (Metric + direction + rough magnitude.)_

## Out of scope
_What are we explicitly not trying to solve? Prevents scope creep later._

## Open questions
_The 3–5 questions that research (phase 3+) needs to answer._

> We believe that `<user segment>` experiences `<problem>` when `<context>`. Solving it would unlock `<outcome>`, measurable by `<signal>`.
